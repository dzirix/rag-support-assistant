# Aide — Code de confirmation (OTP)

> Document fictif de base de connaissances (NovaBank, banque fictive).

## À quoi sert le code reçu par SMS ?

Le code à 6 chiffres confirme que la personne qui signe est bien celle dont l'identité a été vérifiée. Il fait partie de la preuve de signature, avec l'horodatage du consentement.

## Combien de temps le code est-il valable ?

Le code est valable **10 minutes**. Après expiration, vous pouvez demander un nouveau code depuis l'écran de signature.

## Je n'ai pas reçu le code, que faire ?

1. Vérifiez que le numéro de mobile affiché à l'écran est le bon.
2. Patientez 2 minutes : l'envoi peut être retardé.
3. Demandez un nouvel envoi depuis l'écran de signature.
4. Si le problème persiste, contactez votre conseiller : le numéro déclaré devra peut-être être mis à jour.

## Que se passe-t-il après 3 codes erronés ?

Après **3 saisies erronées**, le code est invalidé et le parcours expire, par sécurité. Votre conseiller peut initier un nouveau parcours.
