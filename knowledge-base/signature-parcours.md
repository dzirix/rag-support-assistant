# Aide — Signer son contrat en ligne

> Document fictif de base de connaissances (NovaBank, banque fictive).

## Comment se déroule la signature en ligne ?

1. Vous recevez un lien personnel par SMS ou e-mail lorsque votre contrat est prêt à signer.
2. Vous vérifiez votre identité en photographiant votre pièce d'identité.
3. Vous lisez le contrat en intégralité.
4. Vous confirmez votre accord en cochant la case prévue.
5. Vous saisissez le code à 6 chiffres reçu par SMS pour signer.

Le parcours complet prend en général moins de 5 minutes.

## Combien de temps le lien de signature reste-t-il valable ?

Le lien est valable **7 jours** à compter de son envoi. Passé ce délai, le parcours expire : contactez votre conseiller, qui pourra générer un nouveau lien.

## Que se passe-t-il si je ne termine pas le parcours ?

Rien n'est signé tant que vous n'avez pas saisi le code de confirmation. Vous pouvez reprendre le parcours plus tard avec le même lien, tant qu'il n'a pas expiré.
